What kind of engineer I am

Design systems is a frontend specialty that sits between design, product, and every other engineering team. I ship the pieces features are made of: components, tokens, documentation, and the release pipeline that gets them into a dozen repositories without breaking anything.

The work is invisible when it goes well. A component I redesign might show up in any environment, so a good decision quietly pays off for years, and a bad one is expensive to undo. Most of the job is thinking it through carefully and writing down why.

What I'm working on

Middle truncation in CSS

One day at work I got frustrated at how inaccessible current solutions are for displaying middle truncation on browser, so I started writing an CSS explainer draft to get it into the CSS-overflow-4 standards. I hope soon browsers will have native support for it!

Today this takes JavaScript measurement hacks. They're slow, they break with bidirectional text, and screen readers end up announcing the shortened string instead of the real one. It should be a two line CSS declaration.
