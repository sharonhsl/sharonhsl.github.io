What I'm working on

Middle truncation in CSS

One day at work I got frustrated at how inaccessible middle truncations are displayed on browser, so I started writing an CSS explainer draft to get it into the CSS-overflow-4 standards. I hope soon browsers will have native support for it!

Middle truncation is quite important for showing technical data like URL or filenames in a tight column, where the beginning and end are equally important for users tell items apart. Today we're still using JavaScript to achieve middle truncation. These solutions break with bidirectional text, and screen readers end up announcing the shortened string instead of the actual one if aria labelling is not taken care of. Having browser native support will address accessibility and performance issues all at once.
